Synapse Web Clipper is a free browser extension that lets you highlight pages and save web content to your vault.

## Install Web Clipper

Get the Synapse Web Clipper extension from the official directory for your browser:

- [Chrome Web Store](https://chromewebstore.google.com/detail/synapse-web-clipper/cnjifjpddelmedmihgijeibhnjfabmlf)
	- For Chrome, Brave, Arc, Orion, and other Chromium-based browsers.
- [Firefox Add-Ons](https://addons.mozilla.org/en-US/firefox/addon/web-clipper-synapse/)
	- For Firefox and Firefox Mobile.
- [Safari Extensions](https://apps.apple.com/us/app/synapse-web-clipper/id6720708363)
	- For macOS, iOS, and iPadOS.
- [Edge Add-Ons](https://microsoftedge.microsoft.com/addons/detail/synapse-web-clipper/eigdjhmgnaaeaonimdklocfekkaanfme)
	- For Microsoft Edge.

## Privacy

Synapse Web Clipper saves content locally to your Synapse vault and follows our [privacy policy](https://synapse.md/privacy). Your data is not collected, and we do not gather any usage metrics. The code is [open source](https://github.com/synapsemd/synapse-clipper) and auditable.
