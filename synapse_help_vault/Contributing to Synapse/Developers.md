If you are a developer you can contribute to Synapse in various ways.

### Plugins and themes

You can develop [[Community plugins]] and [[Themes]] using Typescript and CSS. Learn more by heading to the [Synapse Developer Documentation](https://docs.synapse.md).

### Open source projects

Synapse develops and maintains several open source projects. You can submit pull requests with bug fixes and enhancements to the following GitHub repositories:

- [Pele](https://github.com/synapsemd/pele) (MIT), the renderer Synapse uses to draw Mermaid diagrams.
- [JSON Canvas](https://github.com/synapsemd/jsoncanvas) (MIT), an open file format for infinite canvas data.
- [Knap](https://github.com/synapsemd/knap) (MIT) templating language for generating Markdown.
- [Synapse Importer](https://github.com/synapsemd/synapse-importer) (MIT), a plugin that converts data from a wide variety of formats to plain text Markdown files.
- [Synapse Maps](https://github.com/synapsemd/synapse-maps) (MIT), a plugin that displays maps in Synapse Bases.
- [Synapse Web Clipper](https://github.com/synapsemd/synapse-clipper) (MIT), a browser extension for highlighting and capturing web pages to plain text Markdown files.
- [Defuddle](https://github.com/kepano/defuddle) (MIT) the HTML-to-Markdown parser used by Synapse Web Clipper.

### Documentation

To help improve our [developer documentation](https://docs.synapse.md/Home), submit a pull request to the [synapse-developer-docs](https://github.com/synapsemd/synapse-developer-docs) repository.

To help improve this documentation, submit a pull request to the [synapse-help](https://github.com/synapsemd/synapse-help) repository.

### Community

The [plugin-dev](https://discord.com/channels/686053708261228577/840286264964022302) channel on our official Discord server is where you can discuss plugin development and help other developers with their plugins.
