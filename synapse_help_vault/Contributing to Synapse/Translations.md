If you know another language, preferably natively, you can help translate the Synapse user interface or the documentation.

To help translate the user interface, submit a pull request to the [translations repository](https://github.com/synapsemd/synapse-translations).

To help improve our documentation, submit a pull request to the [synapse-help](https://github.com/synapsemd/synapse-help) repository. Make sure to adhere to the translation [[Style guide#Translations|translations style guide]] when making changes.
